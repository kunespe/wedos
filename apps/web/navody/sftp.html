Připojení přes SFTP

Soubory webu nahrajete přes SFTP, šifrovaný přenos souborů přes SSH. Funguje ve FileZille, WinSCP i v terminálu.

Přihlašovací údaje

PoložkaHodnota
ProtokolSFTP (SSH File Transfer Protocol), ne FTP
Serverfirma.cz nebo 2.31.25.249
Port22
Uživatelpošleme po zřízení služby
OvěřeníSSH klíč (doporučujeme) nebo heslo

Web se zobrazuje ze složky htdocs/firma.cz ve vašem domovském adresáři. U některých frameworků (Laravel, Symfony) z její podsložky public.

FileZilla

  1. Otevřete Soubor › Správce míst a klikněte na Nové místo.
  2. Protokol: SFTP. Hostitel: firma.cz, port 22.
  3. Typ přihlášení: Normální pro heslo, nebo Soubor s klíčem a vyberte soukromý klíč.
  4. Klikněte na Připojit. Při prvním připojení potvrďte otisk klíče serveru.

WinSCP

  1. V okně Přihlásit zvolte Nové místo, přenosový protokol SFTP.
  2. Název hostitele firma.cz, port 22, uživatelské jméno.
  3. Pro klíč: Pokročilé › SSH › Ověření › Soubor privátního klíče. Klíč z OpenSSH vám WinSCP nabídne převést do formátu .ppk.
  4. Uložit a Přihlásit.

Přihlášení klíčem místo hesla

Klíč je bezpečnější než heslo a nemusíte si ho pamatovat. Na macOS, Linuxu i ve Windows (PowerShell) ho vytvoříte stejně:

ssh-keygen -t ed25519 -C "jana@notebook"

Vzniknou dva soubory. ~/.ssh/id_ed25519 je soukromý klíč, ten nikomu neposílejte. ~/.ssh/id_ed25519.pub je veřejný: jeho obsah vložte v klientském panelu do požadavku Přístup SFTP / SSH. Jakmile klíč přidáme, připojíte se i z terminálu:

sftp uzivatel@firma.cz
Hesla e-mailem neposíláme.Nové heslo vám předáme bezpečnou cestou a stejně tak prosíme vás: hesla nepište do e-mailů ani do požadavků.

Časté potíže

  • Vypršel časový limit nebo spojení odmítnuto: zkontrolujte, že máte protokol SFTP a port 22, ne FTP a port 21.
  • Permission denied: překlep v uživatelském jméně, nebo klíč, který server ještě nezná. Po několika chybných pokusech server IP adresu na chvíli zablokuje, chvíli počkejte.
  • Soubory jsou nahrané, ale web se nemění: nahráváte do jiné složky, nebo web drží starou verzi v cache (u WordPressu ji vyprázdněte v cache pluginu).
